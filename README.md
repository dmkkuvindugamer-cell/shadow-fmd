## 🟢 About SHADOW FMD

**SHADOW FMD** is a WhatsApp multi-device bot built with Node.js and Baileys.

Designed with a Hacker Green theme, SHADOW FMD aims to provide useful automation, entertainment, group management and utility features.

- 🟢 Bot Name: SHADOW FMD
- ⚡ Prefix: `.`
- 🤖 Platform: WhatsApp
- 💻 Framework: Baileys
- 🟢 Theme: Hacker Green
- 📦 Version: 7.0.0

## 📥 Installation

### 1. Clone Repository

```bash
git clone https://github.com/Fred1e/Fee-Xmd.git
cd Fee-Xmd
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Settings

Edit `config/settings.js`:

```js
export const botname = 'SHADOW FMD';
export const prefix = '.';
```

Configure your session and other required environment variables using your project's existing configuration system.

### 4. Start Bot

```bash
npm start
```

## 🛠 Troubleshooting

**QR Code Not Showing**
- Check your internet connection.
- Verify that the required dependencies are installed.
- Check deployment logs.

**Bot Not Responding**
- Verify the WhatsApp session.
- Check the bot process.
- Restart the application if necessary.

**Deployment Failed**
- Check environment variables.
- Verify Node.js compatibility.
- Check platform logs.
